# DESIGN.md — PickBeon (native)
## 오버레이
- 전체 딤 + 선택영역 컷아웃, 치수 표시, 리사이즈 핸들, loupe, 액상글래스 툴바 5개
## 에디터 (980×620, 리사이즈)
- 좌 이미지+번호박스+호버툴팁+클릭연동, 번역오버레이 ON/OFF (줄분할 매핑, 개수 불일치 시 앞부분만)
- 주석도구: 펜/화살표/박스/텍스트 (정규화 좌표, 실행취소/전체지우기, 복사·핀에 합성 포함)
- 우 OCR TEXT/번역 탭, 존댓말/캐주얼 토글 (변경 시 재번역), 복사, Pin to screen
## 팝업
